# Lab 07 – Introduction to N-Dimensional Arrays with Nested Loops

C solutions for the Lab 07 home tasks: 2D arrays, 3D arrays, and nested loops.

## Topics Covered

- Two-dimensional arrays (grids, row/column traversal)
- Three-dimensional arrays (layers, rows, columns)
- Nested loops (including programs that need no array at all)
- Input validation, searching for max values, running totals and averages
- Pattern printing with loops
